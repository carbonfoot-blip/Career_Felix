## 🤖 Fonctionnement de l'Agent d'Optimisation ATS
Dès qu'une nouvelle opportunité d'emploi se présente :
1. **Fournir l'URL ou le texte de l'offre** à l'assistant AI / Agent.
2. L'agent analyse les critères de qualification, les mots-clés requis et les priorités de l'entreprise.
3. Il génère automatiquement :
   - Une version spécifique du CV (FR et EN) mettant en relief les réalisations concordantes.
   - Une lettre de motivation personnalisée démontrant une valeur ajoutée immédiate.
   - L'ajout transparent dans le Hub interactif `index.html`.
